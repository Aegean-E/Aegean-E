Privacy

A short, concrete account of the data this site does and does not handle.

Short version

This site has no accounts, cookies, analytics, advertising, trackers or external fonts. A certificate pasted into the verifier is never uploaded. The only third-party requests are the public GitHub endpoints needed for the atlas, dossiers and license register.

What is requested, and when

Page or actionRequestWhy
Any pageGitHub Pages serves the HTML, CSS and JavaScriptHosting; GitHub receives standard request metadata such as IP address, user agent and time.
Projects atlasapi.github.com/users/AegeanWorks/reposPublic titles, descriptions, topics and license metadata. Credentials are omitted and the referrer is suppressed.
Project dossieratlas-snapshot.json and a public README endpointProject metadata and a text-only README excerpt. Only the repository name is sent.
License verifierraw.githubusercontent.com/AegeanWorks/Aegean-LicensingThe canonical register, terms registry and cited agreement. The certificate stays in the browser.

Local storage and exports

The atlas stores its public repository response in sessionStorage for up to ten minutes so repeat views do not hit the GitHub API. Live apps keep their progress in localStorage on your device. No certificate is stored there, and no game data is sent to a server. Copy and download actions are initiated by you and stay on your machine.

Email sent to the contact address is handled by the mail provider and used only to answer the inquiry.
