How this works

  1. Your browser reads the certificate locally and recomputes its SHA-256 digest.
  2. That id and digest must match an entry in the canonical public register.
  3. The register status, the cited agreement, the scope, the tier, the dates and the optional project check are then validated.

A digest alone is not proof: anyone can recompute one. The register is the public proof of issuance, and the signing key never reaches this page. Copying the verifier cannot produce a valid new certificate.

The register is fetched from raw.githubusercontent.com when this page loads; that request carries no certificate data. Certificate values are rendered as text. No tracker runs here.

This page is a convenience. For a trust-minimized check, run the public Python verifier or follow the canonical specification; a page you did not audit cannot prove its own integrity.

    Verify without a browser

    The public Python package performs the same register and terms checks, and the private operations tooling is the only place where the HMAC signature can be checked.

    python -m aegean_licensing verify license_certificate.json --register licenses/issued.json

    Read the canonical verification specification or the package README.
